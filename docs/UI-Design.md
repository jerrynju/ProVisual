# ProRF UI 设计说明 v2 —— 以通用模块化仿真软件（Simulink 范式）重构

> 本版从「通用 block-diagram 仿真器」的视角重写交互模型，取代 v1 中「列表式 App + 每节点一个高亮值」的假设。核心转变：**画布是中心，浏览靠左侧抽屉，模块输出是任意类型，调试是一等公民，子系统是层级化的**。

---

## 0. 范式转变（与 v1 的根本差异）

| 维度 | v1（移动 App 思维） | v2（Simulink 仿真器思维） |
|---|---|---|
| 中心对象 | 工作流*列表* | **模型画布（block diagram）** |
| 浏览入口 | 底部 5 Tab | **左侧滑出抽屉**（模型树 + 库 + 模板 + 场景） |
| 模块表达 | 每节点一个高亮 dB 值 | **端口 + 参数 + 任意类型输出**，数值是可选摘要 |
| 运行 | 一次性出结果 | **运行 / 单步 / 断点 / 探针** 的可调试执行 |
| 组织 | 扁平节点链 | **子系统层级**（下钻 / 面包屑 / 掩码 / 变体） |
| 底栏 | 资源切换 | **运行-调试工具条**（仿真控制） |

设计目标：让用户像在 Simulink 里一样「搭模型 → 连信号 → 配参数 → 跑/单步 → 看波形/诊断 → 下钻子系统」。

---

## 1. 总体布局（三区 + 两抽屉）

桌面/平板为理想布局，手机为其塌缩形态：

```
┌───────────────────────────────────────────────┐
│  顶部工具条：模型名 ▾ │ 撤销 重做 │ 运行▶ 单步⏯ 停止■ │ 缩放 适应 │ ⋮ │
├──────┬───────────────────────────────┬─────────┤
│ 左抽屉│           中央画布            │ 右检查器 │
│(模型树│      (block diagram canvas)   │(Inspector│
│ /库/  │   节点框+端口+连线+网格        │ 输入/参数 │
│ 模板/ │   选中块高亮、信号探针          │ /输出/诊断│
│ 场景) │                               │ /图表)   │
├──────┴───────────────────────────────┴─────────┤
│  底部停靠区：信号检视器 / 诊断台 / 执行日志（可上拉）  │
└───────────────────────────────────────────────┘
```

- **左抽屉（从左向右滑出）**：浏览与取用一切素材，见 §2。
- **中央画布**：唯一的"主角"，常驻。
- **右检查器**：选中块/连线时滑出，编辑参数、查看端口与输出，见 §5。
- **底部停靠区**：上拉式 BottomSheet，承载调试三件套（信号检视器 / 诊断台 / 日志），见 §6。

**响应式塌缩（手机）**：
- 左抽屉 = `ModalNavigationDrawer`（手势从左缘右滑唤出，遮罩式）。
- 右检查器 = 底部上拉 BottomSheet（选中块时半屏弹出）。
- 顶部工具条图标化；运行-调试控制收进底部一条固定的 **仿真控制条**。
- 平板/横屏：左抽屉与右检查器变为**常驻停靠面板**（`DismissibleNavigationDrawer` 风格），更接近桌面 Simulink。

## 2. 左侧抽屉：模型树 + 多个库（取代底部 Tab）

抽屉内用分段 Tab 切换四个浏览器，全部「从左向右滑」唤出：

1. **模型浏览器（Model Browser）**：当前项目下所有模型/工作流，以及每个模型内部的**子系统层级树**（可展开）。点击 = 在画布打开/下钻。体现"工程是多个子系统的组合"。
2. **库浏览器（Library Browser）**：节点/块的调色板，按域分类（链路源 / 有源 / 无源 / 天线 / 信道 / 测量 / 子系统 / 自定义）+ 搜索。**从库里把块拖到画布**即实例化（palette→canvas 拖拽）。
3. **模板（Templates）**：完整工作流模板，一键新建模型。
4. **场景（Scenarios）**：参数集/工况预设，应用到当前模型做对比。

> 这样底部不再用于"换页"，而专注仿真控制；浏览与搭建在左抽屉内完成，符合仿真软件"库浏览器常驻左侧"的心智。

## 3. 模块（Block）模型：不假设单一高亮值

每个块由四部分声明式定义（对齐 Build Spec 的 NodeDefinition/Instance/Executor/UI）：

- **端口（Ports）**：带**数据类型与单位/量纲**的输入/输出口。信号可为标量、向量、频谱、矩阵、总线(bus)。端口在卡片左右两侧以小圆点呈现，连线携带类型颜色。
- **参数（Parameters）**：`值+单位+量纲`，在检查器以表单编辑。
- **输出（Outputs）**：执行后产生，**类型任意**。
- **显示描述符（Display Descriptors）**：块**自己声明**卡片上显示什么，数量 0..n：
  - 无（纯路由/Mux/Bus 块 → 卡片只有标题+端口）
  - 标量徽章（如放大器 +23 dB）
  - 迷你火花线/缩略频谱（如滤波器幅频曲线）
  - 多 KPI（如接收机：灵敏度 + 噪声系数 + 余量）
  - 矩阵/表格指示（如 S 参数块 → 显示 "2×2 S-params"）

**节点卡片统一结构**（§9 泛化）：`标题 + 类型图标 + 状态 + [0..n 个显示描述符] + 端口摘要`。
**状态（Status）**取代"必然有值"的假设：`未配置 / 就绪 / 计算中 / 已计算 / 数据过期(dirty) / 错误 / 禁用`，用色点+图标表达。

## 4. 画布与视图

中央画布提供三种等价视图（顶部分段或视图菜单切换）：

- **拓扑视图（Block Diagram）**：默认。块框+端口+贝塞尔连线+点状网格，支持框选、多选、缩放平移、对齐吸附。选中块高亮，连线显示信号类型/单位。
- **流程视图（List / Execution Order）**：按拓扑执行顺序的线性列表，便于审阅级联；每行复用"节点卡片"结构（含 0..n 显示描述符，不强求数值）。
- **数据/信号视图**：以信号为中心的表格，列出每条连线的类型、维度、当前值/统计，便于排查。

**子系统在画布上的表达**：子系统块显示为带"⊞ 下钻"角标的复合块；双击进入其内部画布。

---

## 5. 右侧检查器（Inspector，泛化）

随选中对象变化（块 / 连线 / 子系统 / 画布空白）：

- 选中**块**：Tab = **输入 / 参数 / 输出 / 诊断 / 图表**
  - 输入/输出按**端口类型**自适应渲染：标量→值+单位；向量→迷你列表；频谱/曲线→图表；矩阵→表格；总线→可展开树。
  - 参数：值+单位+量纲表单，带校验（范围/量纲）。
- 选中**连线/信号**：类型、维度、源/宿、当前值，"加为探针"。
- 选中**子系统**：若有**掩码(Mask)**，显示掩码参数对话框；否则显示其端口与"进入内部"。
- 选中**画布**：模型级配置（求解器/采样/单位制/全局参数）。

---

## 6. 调试（Debugging，一等公民）

底部上拉停靠区 + 工具条联动，提供仿真器级调试：

1. **执行控制**：运行 / 单步(Step) / 连续步进 / 暂停 / 停止。单步时画布**高亮当前求值块**，按拓扑序推进。
2. **断点(Breakpoints)**：在块或连线上设断点；命中即暂停并聚焦。
3. **信号探针 / 检视器(Data Inspector)**：点连线/端口"加探针"，在底部检视器里实时绘制所选信号（多信号叠加、游标读数、运行间对比）。
4. **诊断台(Diagnostics)**：错误/警告列表（未连接端口、量纲/类型不匹配、代数环 algebraic loop、参数越界），点击**跳转到对应块**并高亮。
5. **执行状态叠加**：块显示 idle/computing/done/**dirty(过期)**/error；改参数后下游标记为过期，提示增量重算。
6. **日志与重放**：执行日志、信号记录(logging)、断言(assertion)；工作流 JSON 可回放（对齐 Spec §8/§11）。

## 7. 子系统与多模型（层级与复用）

- **子系统(Subsystem)**：用 Inport/Outport 定义外部端口的复合块；**双击下钻**进入内部画布，顶部**面包屑**导航：`顶层 模型 ▸ 发射链路 ▸ 上变频`，逐级返回。
- **模型浏览器树**反映层级，点击任意层级即定位。
- **掩码(Mask)**：子系统可暴露一组精简参数（隐藏内部细节），对外像一个普通带参数块。
- **库链接 / 引用模型**：可复用子系统从库链接进多个模型；**变体子系统(Variant)** 按配置切换实现（如 不同频段前端）。
- **总线(Bus)**：跨子系统边界的信号分组，减少连线。
- **多模型项目**：一个项目含多个顶层模型，经模型浏览器切换；子系统可跨模型复用。

## 8. 屏幕清单（v2）与关系

| 屏幕/面板 | 角色 | 进入方式 |
|---|---|---|
| 画布（拓扑/流程/数据三视图） | 主工作区 | 启动即在此；模型浏览器选模型 |
| 左抽屉·模型浏览器 | 层级/多模型导航 | 左缘右滑 / 工具条「浏览」 |
| 左抽屉·库浏览器 | 块调色板（拖拽实例化） | 抽屉内 Tab |
| 左抽屉·模板 / 场景 | 一键建模 / 工况预设 | 抽屉内 Tab |
| 右检查器 | 块/连线/子系统/模型属性编辑 | 选中对象时滑出 |
| 底部·信号检视器 | 探针波形/数值 | 加探针 / 上拉 |
| 底部·诊断台 | 错误警告 + 跳转 | 校验/运行后 / 上拉 |
| 底部·执行日志 | 运行记录/重放 | 上拉 |
| 子系统内部画布 | 层级下钻 | 双击子系统块 / 面包屑 |
| 结果/分析 | 链路预算汇总与图表 | 运行后从工具条「结果」 |
| 设置 / 账户 | 求解器、单位制、订阅 | 工具条 ⋮ / 模型菜单 |

**关系要点**：
- **画布为枢纽**：左抽屉「取用」→ 画布「组装/连线」→ 右检查器「配参」→ 底部「调试/看信号」→ 结果「汇总」→ 下钻「进入子系统」，构成同屏闭环，而非多页跳转。
- **层级是导航主轴**：面包屑 + 模型树管理"从顶层到子系统"的纵深，取代 v1 的"列表→详情→编辑器"线性栈。
- **资源是叠加面板而非页面**：库/模板/场景以抽屉浮层叠加在画布上，用完即收，保持上下文不丢失。

## 9. 相对当前实现的差距与迁移建议（增量、对齐 Spec「一次一个最小闭环」）

1. **泛化节点模型**：给 NodeDefinition 增加 `displayDescriptors`（0..n）与端口数据类型；UI 卡片去掉"必有 headline"假设（M1）。
2. **左抽屉**：将现 5 个底部 Tab 中的 库/场景/模板/工作流 收入 `ModalNavigationDrawer`，底栏改为仿真控制条（M1）。
3. **检查器按端口类型渲染**：输出区支持 标量/向量/频谱/表格（M2）。
4. **调试 MVP**：执行状态叠加 + 诊断台 + 单步高亮（引擎已具备拓扑执行，可在其上加 step/breakpoint 钩子）（M2）。
5. **子系统**：NodeDefinition 支持"含子图"，画布支持下钻+面包屑；模型树展示层级（M3）。
6. **响应式**：手机=模态抽屉+底部 Sheet 检查器；平板=常驻停靠（M3）。

> 以上每步均可独立交付、可单测（引擎层 JVM 测试），不破坏现有分层。
